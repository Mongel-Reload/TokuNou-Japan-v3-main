# TokuNou Japan

Versi revisi mempertahankan visual website asli dan memperbaiki arsitektur navigasi.

## Perubahan utama
- Menu navbar dan menu hamburger mengarah ke halaman baru, bukan anchor panjang di beranda.
- Beranda diringkas menjadi landing page agar tidak terlalu panjang.
- Konten detail tetap tersedia di halaman khusus.
- Ditambahkan Roadmap, Cek Kesiapan, Quiz, Peta Penempatan, dan Tentang TokuNou.
- Semua referensi domain lama diperbaiki menjadi link relatif.
- Tidak ada CSS tema baru yang mengganti identitas visual halaman asli.

- cek-kesiapan.html
- quiz.html
